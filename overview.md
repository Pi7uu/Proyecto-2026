# Overview del Proyecto

**Lustre & Lineage** es un e-commerce de joyería en plata 925 con estética minimalista de lujo editorial. Su propósito es vender piezas curadas (anillos, collares, aros, tobilleras y dijes) a través de una experiencia de compra elegante, sobria y fluida. El proyecto combina un backend Django con API REST y un frontend React con páginas SSR, para cubrir el flujo completo de catálogo, carrito, checkout y gestión de órdenes.
